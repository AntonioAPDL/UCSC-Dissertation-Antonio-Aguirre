This appendix provides the nonstandard posterior calculations used in
Chapter~\ref{ch:research-a}. The remaining state updates use the standard

\section{Posterior targets and state augmentation}
\label{app:exdqlm-posterior}

For the dynamic model, the exAL augmentation is
\begin{align}
y_t\mid\vect\theta_t,\sigma,\gamma,v_t,s_t
&\sim\N\{\mat F_t^\top\vect\theta_t+C_\gamma\sigma|\gamma|s_t
 +A_\gamma v_t,\,\sigma B_\gamma v_t\},\nonumber\\
v_t\mid\sigma&\sim\Exp(\text{rate}=1/\sigma),
&s_t&\sim\TNp(0,1),\nonumber\\
\vect\theta_t\mid\vect\theta_{t-1}
&\sim\N(\mat G_t\vect\theta_{t-1},\mat W_t).
\label{exd:eq:dyn_exdqlm_joint}
\end{align}
Conditional on \((\sigma,\gamma,\vect v,\vect s)\), the state trajectory has
a Gaussian full conditional. Fixing \(\gamma=0\) removes \(s_t\) and gives
the AL model. Static regression replaces the state location by
\(\vect x_i^\top\vect\beta\) and uses the corresponding weighted Gaussian
coefficient update.

For transfer-function models, append the accumulated input effect \(\zeta_t\)
and instantaneous coefficients \(\vect\psi_t\) to the base state. Their
evolution block is
\begin{equation}
\begin{pmatrix}\zeta_t\\\vect\psi_t\end{pmatrix}
=
\begin{pmatrix}\lambda&\mat x_t^\top\\\mat 0_k&\mat I_k\end{pmatrix}
\begin{pmatrix}\zeta_{t-1}\\\vect\psi_{t-1}\end{pmatrix}
+\text{Gaussian innovation}.
\label{exd:eq:tf_aug_state}
\end{equation}
The same state-space calculations then apply to the enlarged trajectory.

For static sparse regression, the regularized horseshoe gives effective
prior precision
\[
\omega_j^{\mathrm{prior}}
=\tau^{-2}\lambda_j^{-2}+\zeta^{-2}.
\]
The half-Cauchy auxiliary representation supplies inverse-gamma scale updates
\citep{exd-nishimura2023shrunken}; it changes the coefficient precision but
not the likelihood target.

\section{Structured scale--skewness approximation}
\label{app:exdqlm-ldvb}

The nonconjugate component is the \((\sigma,\gamma)\) block. The current
variational approximation uses
\[
q(\vect\theta_{0:T})\prod_{t=1}^Tq(v_t)q(s_t)\,
q(\gamma)q(\sigma\mid\gamma),
\]
with \(q(\vect\beta)\) replacing the state factor in static regression.
For each admissible \(\gamma\), the conditional scale factor has a GIG
kernel. Quadrature on the bounded logit coordinate for \(\gamma\) supplies
the weights, conditional GIG moments, and approximate joint draws.

The Gaussian state coordinate requires the mixed moments
\begin{align}
\kappa_1&=\E\{1/(\sigma B_\gamma)\},&
\kappa_2&=\E\{A_\gamma/(\sigma B_\gamma)\},&
\kappa_4&=\E\{C_\gamma|\gamma|/B_\gamma\}.
\label{exd:eq:dyn_exdqlm_kappa}
\end{align}
If \(m_{1/v,t}=\E(v_t^{-1})\) and
\(\bar s_t=\E(s_t)\), its conditional precision and pseudo-response are
\begin{equation}
\phi_t=\kappa_1m_{1/v,t},
\qquad
y_t^{\mathrm{VB}}
=\{y_t\phi_t-\kappa_2-\kappa_4\bar s_tm_{1/v,t}\}/\phi_t.
\label{exd:eq:dyn_exdqlm_vb_pseudo}
\end{equation}
The remaining coordinates are GIG for \(v_t\), positive-truncated normal for
\(s_t\), and inverse-gamma for conjugate scale auxiliaries. Their rates use
current state, residual, and mixed scale--skewness moments. The structured
factor preserves dependence that would be lost by multiplying separate
expectations of \(\sigma\) and \(\gamma\).

The earlier Laplace--delta method instead approximates transformed
\((\log\sigma,\gamma)\) coordinates by a Gaussian at a local mode and uses
second-order delta moments. Both methods approximate the declared posterior;
MCMC remains the reference when posterior tails or interval widths are
consequential.

\section{Forecasting and posterior-predictive synthesis}
\label{app:exdqlm-synthesis}

At a forecast origin, each posterior or variational draw propagates the state
through its evolution equation and then draws a future response from the
corresponding AL or exAL observation model. These are response-level draws,
not draws of the fitted quantile location alone.

Quantile synthesis combines separately fitted levels by correcting crossings
as requested and interpolating level-specific predictive curves on a common
response scale. It remains a post-fit construction, not a joint multiquantile
posterior.
